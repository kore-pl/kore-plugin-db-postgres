# 变更记录 — PostgreSQL 管理插件

版本采用语义化版本 `vMAJOR.MINOR.PATCH`：新增功能 minor，修复/文档 patch。历史 tag 不重签、不删除。

## 当前版本 0.4.0

详见仓库 [CHANGELOG.md](https://github.com/kore-pl/kore-plugin-db-postgres/blob/main/CHANGELOG.md) 与 [Releases](https://github.com/kore-pl/kore-plugin-db-postgres/releases)。本仓最近一次发版为 `0.4.0`，变更条目见仓库 CHANGELOG。

## 约定

- `feat` → minor；`fix` / `docs` → patch。
- 每个版本附中文说明；签名 tag 可用 `git tag -v` 验证。
- 多次提交、少推送；普通分支不 push。
